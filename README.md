# FF Stanzza

A 1:1 local recreation of https://stanzza.design/awards under the FF Dev Studio identity, built
2026-09-16 with the reference-clone skill. Static Vite site: the reference's stylesheet and
markup carried verbatim (class names 1:1), every Webflow/GSAP/Swiper behaviour re-implemented
in `src/js/`.

```bash
npm install
npm run dev        # http://localhost:3162
npm run build      # dist/ (static, deploy anywhere — ask before deploying)
```

- `docs/brief.md`, `docs/reference-spec.md` — what was built and the measured numbers
- `docs/parity.md` — 42-row ledger (39 complete)
- `docs/qa-log.md` — how it was verified; `tools/` holds the instruments
- `docs/reference/2026-09-16/` — snapshot, assets (+ `manifest.tsv`), IX2/IX3 payloads, shots

The photography, project videos, logo wall, handwriting slogan video and founder portrait are
the reference's — authorised for this local test only and to be replaced before anything public.
